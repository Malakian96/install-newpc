# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Repository Purpose

This is a pure Markdown documentation repository — a curated reference list of software for setting up a new PC. There is no build system, no tests, and no linting. The entire content lives in `README.md`.

The documentation is written in **Spanish**.

## Content Structure

`README.md` is organized into five numbered sections, each rendered as a Markdown table:

1. **Programas Bootables desde un USB** — Bootable USB diagnostic tools (e.g., MemTest86, Hiren's BootCD PE)
2. **Software Instalado en el Sistema Operativo** — Hardware monitoring/benchmarking tools installed on the OS (e.g., CPU-Z, HWMonitor, Prime95, FurMark, 3DMark, CrystalDiskMark)
3. **Aplicaciones Recomendadas para un Desarrollador Web** — Recommended apps for web developers (e.g., VS Code, Git, Docker, XAMPP, Postman, browsers)
4. **Aplicaciones Típicas para un Usuario Promedio** — Typical apps for average users (e.g., VLC, 7-Zip, Spotify, Discord)
5. **Aplicaciones 'Gaming'** — Gaming-related apps (e.g., Steam, Battle.net, Razer Cortex)

## Table Format Convention

Each section uses a consistent Markdown table schema. Sections 1–2 use four columns:

```
| **Software** | **Función Principal** | **Descripción** | **Descarga** |
```

Sections 3–5 use three columns:

```
| **Aplicación** | **Descripción** | **URL de Descarga** |
```

Download links use inline Markdown syntax: `[Label](URL)`. Keep software names **bold** in the first column.

## Adding or Updating Entries

- Match the column schema of the target section exactly.
- Write descriptions and function names in Spanish.
- Use direct download URLs where possible (not landing pages), consistent with existing entries.
- Place new entries in the appropriate section based on the target audience (developer, gamer, average user, etc.).
